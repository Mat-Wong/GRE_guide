# GRE 备考台

一个可离线打开的 GRE 备考网页。本仓库公开，GitHub Pages 未启用；下载整个仓库后可在本地使用。题库包含第三方资料的原始题干与选项，请遵守相应版权与授权条件。

## 功能

- GRE 救命800词：800 条完整词汇已加入背词词库，并默认全部纳入个人生词本导出。
- 个人生词筛选：自动从填空题干/选项、阅读文章/题干/选项中抽取候选词，由用户标记“加入生词本”或“认识”。
- 三轮难度筛选：17,547 个题库候选词经过多轮筛选后保留 1,621 个，过滤日常、高中、简单四六级词、专名和 OCR 噪声，保留 GRE/高阶学术/专业术语/熟词僻义。
- 词义级补全：题库保留词与现有词卡共 5,830 个有效独立词义组合，覆盖 6,485 张词卡；每条都有中文义、对应词义的例句和英文学习者释义，并经语义一致性检查。
- 生词频次与背词：生词筛选和“个人生词本”背词队列均按词在填空＋阅读原题中的出现次数降序，并显示具体次数；加入生词本后会自动进入背词复习池。
- 复习池保留：背词选对只记录正确，不会自动移出复习池；只有点击词卡上的“移除复习池”才会移除。
- 不背单词 TXT：导出 UTF-8 纯文本，每行一个英文词；内容为救命800词 + 用户亲自选中的题目生词，并自动去重。
- 背词：中文释义四选一、模糊/认识/错误状态、答后显示正确含义、助记、例句和 GRE 近义词。
- 词义例句：背词卡优先使用与当前中文词义对应的自然英文例句；`data/gre-source-examples.js` 仅作为未补全词卡的后备原题定位数据。
- 释义选项清洗：背词选项不显示 `(v.)`、`（补充含义）`、`（非舞台）` 等内部词性/区分备注，但判题仍使用完整原始词义。
- 填空：完整导入《填空2000题》，包含单空、双空、三空和六选二；答案来自对应答案 PDF。
- 选项即时生词：填空题提交后，每个选项显示语境中文义，并可一键加入个人生词本；未提交或只查看解析时不显示任何中文提示。
- 题干点词查义：仅在提交后，把解析词汇、各 GRE 词库、救命800词及原题选项词库中命中的词做成可点击词；情感/态度形容词副词和影响逻辑方向的关键动词名词会优先保留，只过滤明确的日常/高中常用词和已标记“认识”的词。
- 阅读：完整导入《阅读440篇》共 891 小题；871 道选项题可直接评分，20 道选句题显示答案 PDF 标注。
- 阅读答后查词：提交阅读题后，文章正文、题干与每个选项中的重点 GRE 词均以虚线标注，可点击查看中文释义，并可加入生词本或标记认识；作答前和只查看答案时不显示。
- 阅读全文翻译：阅读题真实提交后自动展开对应文章的全文翻译与篇章生词；作答前不透露翻译。
- 完整解析：填空含代入答案后的完整翻译、生词释义、逻辑线索、选对原因和干扰项排除；阅读提供预先生成并存放在本地的题目/选项翻译、文章结构与定位、原文证据、推理过程、逐项排除和易错点。使用时不调用外部接口。
- Section 练习：交替生成 12 题（7 填空 + 5 阅读）和 15 题（8 填空 + 7 阅读）的混合难度练习。
- 数学：从《数学900题》中筛选容易出错的中等偏上与困难题，排除基础题、缺图题、抽取不完整题和重复题；作答后题干中的 GRE Quant 术语和较难数学表达可点击查看中文释义，普通英语不标注。
- 进度：保存在浏览器本地，可导出、导入 JSON 文件，不需要账号、服务器或数据库。

## 数据规模

- 词卡：6526 条。
- 填空：2000 题，286 个原始 Section，2000/2000 题答案已对齐。
- 数学：32 道；仅包含经过难度筛选、按选项原文复核的中等偏上与困难题。
- 阅读：440 篇 passage，891 道小题。

题目生词需在工作台中标记“加入生词本”后导出为不背单词 TXT，以确保不把熟词混进去。

## 本地运行

直接双击打开：

```text
index.html
```

词卡、题目、答案、翻译和解析已预先写入 `data/` 中的本地 JavaScript 文件；网页使用时不需要账号、密钥或联网请求。

必须连同 `assets/` 和 `data/` 一起下载，不能只保存 `index.html`。也可以启动本地静态服务器：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8765/
```

## 迁移进度

在旧版备考台点击「导出进度」，保存 `gre-progress.json`。在新版点击「导入进度」，选择该文件。导入会替换当前浏览器中的进度；如果新版里已有记录，页面会先提示并自动下载备份。不同浏览器、`file://` 与本地服务器地址的存储互不相通，请用 JSON 文件迁移。进度文件只保存在你自己的设备上，不应提交到仓库。

## 发布边界

仓库包含 `data/original-practice.js` 和 `data/original-math-practice.js` 等预先生成的题目与解析，但不包含原始 PDF、处理缓存或个人进度。GitHub Pages 未启用；当前只提供源文件下载，不提供在线备考网页。
